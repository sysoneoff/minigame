# Mantiqiy Orol 3D (Godot 4.3 + GitHub Actions Android APK)

Bolalar uchun yorqin low-poly 3D mobil boshqotirma-sarguzasht o‘yini (5 ta orol, 100 ta daraja).

## GitHub Actions orqali APK yaratish
1. Ushbu papkadagi barcha fayllarni yangi GitHub repozitoriyasiga (`main` branchga) push qiling.
2. GitHub’da **Actions** bo‘limini oching — **Build Android APK (Godot 4.3)** workflow avtomatik ishga tushadi.
3. Yig‘ish tugagach (taxminan 3–5 daqiqa), pastdagi **Artifacts → MantiqiyOrol3D-Android-APK** dan tayyor `mantiqiy_orol_3d.apk` faylini yuklab olib Android telefoningizga o‘rnating!
